## Before You Start

A badge is an inline element (`<span>`) that expands to fit its content.

It automatically calculates text contrast (white vs dark text) based on the background color defined by the active theme's `colorContrast` configuration.

The Quick Start example below will render a standard, neutral-colored badge.

## Badge Accessibility Guide

The Badge component is fundamentally static content, meaning its accessibility footprint is small unless the `onRemove` interaction is used.

### Keyboard Shortcuts

*If `onRemove` is provided:*

| Key | Action |
|-----|--------|
| <KeyboardKey>Tab</KeyboardKey> | Moves focus to the 'X' button inside the badge. |
| <KeyboardKey>Enter</KeyboardKey> | Triggers the `onRemove` callback. |
| <KeyboardKey>Space</KeyboardKey> | Triggers the `onRemove` callback. |

### ARIA Attributes

| Attribute | Value | When |
|-----------|-------|------|
| `aria-label` | `"Remove badge"` | Applied to the internal close button when `onRemove` is passed |
| `aria-hidden` | `"true"` | Applied to the dot and icon span elements to hide them from screen readers |


### Screen Reader Behavior

By default, screen readers simply read the text content of the badge in the normal document flow.
If `onRemove` is present, the inner button receives an `aria-label="Remove badge"`, so screen readers will announce: *"React JS, Remove badge, button"*.

### Accessibility Checklist

- [ ] Ensure background/text contrast meets WCAG AA (the component handles this automatically unless you manually override `darkText`).
- [ ] If using an `icon` without any text `children`, ensure the icon itself has an `aria-label` or surrounding visually hidden text.

## Troubleshooting Badge

### Common Mistakes

| Symptom | Wrong ❌ | Right ✅ |
|---------|---------|---------|
| Badge is clickable but has no hover state | Trying to use `<Badge onClick={...}>` | Use `<Button>` or an `ActionMenu` instead; badges don't accept `onClick` directly |
| Badge breaks to multiple lines | Long text in a constrained container | Use the `maxLength` prop, or add `white-space: nowrap` via className |
| Text is invisible (white on white) | Incorrect dark mode setup | The `lightMode` prop forces light backgrounds; ensure your theme handles contrast, or use `darkText={true}` to override |

### Frequently Asked Questions

**Q: Does the badge have a maximum width?**
A: No, it will expand horizontally to fit its contents. If placed inside a strict Flex or Grid container, it may shrink or wrap. Use `maxLength` to ensure it stays compact.

**Q: Can I use an icon inside a badge?**
A: Yes, use the `icon` prop: `<Badge icon={<StarIcon />}>Pro</Badge>`.

**Q: Why doesn't the badge look round when I pass `pill={true}`?**
A: `pill` relies on `border-radius: 9999px`. If you have a global CSS reset that forces `border-radius: 0` on spans with high specificity, you will need to override it via `className`.

**Q: Can I use Badge for main site navigation?**
A: No. Badges are purely informational tags. For primary navigation links, use the `<Button asLink>` or the `<Link>` component directly.
