# Chip

<ComponentStatus status="stable" version="1.0.0" aria="Button" />

Chips are compact, pill-shaped elements that represent an attribute, tag, or action. They are highly versatile and often used for categorizing content, displaying active filters, or acting as removable selections in forms.

## Before You Start

A Chip is visually distinct due to its fully rounded pill shape.
By default, it acts as a static label, but passing `onClick` or `onDelete` turns it into an interactive element.
The Quick Start example below will produce a simple grey pill containing text.

```tsx
      variant={isActive ? "filled" : "outlined"}
      color={isActive ? "primary" : "default"}
      onClick={() => setIsActive(!isActive)}
      aria-label="Toggle filter"
    />
  );
}
```

## Chip Best Practices

Chips can quickly clutter an interface if overused. Keep them focused and concise.

<DoAndDont
  good={`// ✅ Keep labels short and concise
<Chip label="Processing" />`}
  bad={`// ❌ Use sentences inside a chip
<Chip label="Your order is currently being processed in our facility" />`}
/>

<DoAndDont
  good={`// ✅ Use the onDelete callback for removal
<Chip label="React" onDelete={removeTag} />`}
  bad={`// ❌ Pass a custom icon button into the label
<Chip label={<>React <button>X</button></>} />`}
/>

<DoAndDont
  good={`// ✅ Use standard color variants for status
<Chip color="success" label="Paid" />`}
  bad={`// ❌ Force custom background colors that break contrast
<Chip style={{ background: '#0f0' }} label="Paid" />`}
/>

<DoAndDont
  good={`// ✅ Provide aria-labels when the action isn't obvious
<Chip onClick={filter} aria-label="Filter by React" label="React" />`}
  bad={`// ❌ Rely solely on colors to convey interactive state
<Chip onClick={filter} color="primary" label="React" />`}
/>

## Chip Accessibility Guide

Chip adjusts its semantics automatically based on the props provided. If `onClick` or `onDelete` are passed, it becomes a keyboard-focusable, interactive element.

### Keyboard Shortcuts

| Key | Action |
|-----|--------|
| <KeyboardKey>Tab</KeyboardKey> | Focuses the chip (if interactive) |
| <KeyboardKey>Enter</KeyboardKey> | Triggers `onClick` (if interactive) |
| <KeyboardKey>Space</KeyboardKey> | Triggers `onClick` (if interactive) |
| <KeyboardKey>Backspace</KeyboardKey> | Triggers `onDelete` (if focus is on the chip) |
| <KeyboardKey>Delete</KeyboardKey> | Triggers `onDelete` (if focus is on the chip) |

### ARIA Attributes

| Attribute | Value | When |
|-----------|-------|------|
| `role` | `"button"` | When `onClick` or `onDelete` is provided |
| `tabIndex` | `0` | When `onClick` or `onDelete` is provided (and not disabled) |
| `aria-disabled`| `"true"` | When `disabled` is true |

### Screen Reader Behavior

If static, it is read as standard text. If interactive, it announces as a button along with the `label` text. The delete icon automatically has an internal `aria-label="Remove [label]"` for screen readers.

### Accessibility Checklist

- [ ] Use `aria-label` if the chip is a toggle button (e.g., `aria-label="Filter by React"`).
- [ ] Ensure deleted chips immediately shift focus to a logical next element in your app logic.
- [ ] Do not rely solely on color to convey meaning; pair with icons where appropriate.
- [ ] Always test with keyboard-only navigation before shipping

## Chip Design Tokens

<Callout type="tip" title="What are design tokens?">
  Design tokens are CSS custom properties that store design decisions
  like colors, spacing, and radius. Override them to restyle
  Chip without fighting CSS specificity.
</Callout>

| Token | Default Value | Description |
|-------|--------------|-------------|
| `--lxs-chip-bg` | varies by variant/color | Background color |
| `--lxs-chip-color` | varies by variant/color | Text and icon color |
| `--lxs-chip-border` | varies by variant/color | Border color |

**Override globally:**
```css
:root {
  --lxs-chip-bg: var(--lxs-color-neutral-100);
}
```

**Override for one section:**
```css
.custom-theme {
  --lxs-chip-bg: #f0f0f0;
}
```

**Override on one instance:**
```tsx
<Chip
  style={{ '--lxs-chip-bg': '#ffeb3b', '--lxs-chip-color': '#000' } as React.CSSProperties}
  label="Custom Yellow"
/>
```

### Deletable Tag List

Used when: Showing a list of applied filters or selected tags that the user can remove.

<!--
EXAMPLE: Deletable Tag List
PURPOSE: Demonstrates managing an array of tags with removal logic
OUTPUT: A row of chips that disappear when their X is clicked
USE WHEN: Creating tag inputs or active filter displays
SOURCE: app/storybook/src/stories/Chip.stories.ts → Deletable
-->
```tsx
import { useState } from 'react';
import { Chip } from '@luxis-ui/core';

export default function TagList() {
  const [tags, setTags] = useState([
    { id: '1', label: 'React', color: 'primary' as const },
    { id: '2', label: 'TypeScript', color: 'info' as const },
    { id: '3', label: 'Node.js', color: 'success' as const }
  ]);

  const handleRemove = (idToRemove: string) => {
    setTags(tags.filter(tag => tag.id !== idToRemove));
  };

  return (
    <div style={{ display: 'flex', flexWrap: 'wrap', gap: '8px' }}>
      {tags.map(tag => (
        <Chip
          key={tag.id}
          label={tag.label}
          color={tag.color}
          variant="light"
          onDelete={() => handleRemove(tag.id)}
        />
      ))}
      {tags.length === 0 && <span style={{ color: '#666', fontSize: '14px' }}>No tags selected.</span>}
    </div>
  );
}
```

### Filter Group

Used when: Users need to toggle categories on and off to filter content.

<!--
EXAMPLE: Filter Group
PURPOSE: Demonstrates chips acting as toggle buttons
OUTPUT: A group of chips that fill with color when active
USE WHEN: Building category selectors or search filters
SOURCE: app/storybook/src/stories/Chip.stories.ts → Filter Group
-->
```tsx
import { useState } from 'react';
import { Chip } from '@luxis-ui/core';

export default function FilterGroup() {
  const [activeFilters, setActiveFilters] = useState<Set<string>>(new Set(['frontend']));

  const filters = [
    { id: 'frontend', label: 'Frontend' },
    { id: 'backend', label: 'Backend' },
    { id: 'devops', label: 'DevOps' }
  ];

  const toggleFilter = (id: string) => {
    const next = new Set(activeFilters);
    if (next.has(id)) {
      next.delete(id);
    } else {
      next.add(id);
    }
    setActiveFilters(next);
  };

  return (
    <div style={{ display: 'flex', gap: '8px' }}>
      {filters.map(f => (
        <Chip
          key={f.id}
          label={f.label}
          variant={activeFilters.has(f.id) ? 'filled' : 'outlined'}
          color={activeFilters.has(f.id) ? 'primary' : 'default'}
          onClick={() => toggleFilter(f.id)}
          aria-label={`${activeFilters.has(f.id) ? 'Remove' : 'Add'} ${f.label} filter`}
        />
      ))}
    </div>
  );
}
```

```tsx
          variant="light"

      </div>
    </div>
  );
}
```

## Troubleshooting Chip

### Common Mistakes

| Symptom | Wrong ❌ | Right ✅ |
|---------|---------|---------|
| Delete button doesn't appear | Using `onClick` only | Pass a function to `onDelete` |
| Text overflows the chip | Passing a paragraph of text | Use short, concise strings |
| Cannot tab to the chip | Using it without onClick/onDelete | Chips are static unless handlers are passed |
| Avatar image looks distorted | Using a rectangular image | Images will be rounded, use square assets |

### Frequently Asked Questions

**Q: Why doesn't the Chip delete itself when I click the X?**
A: Chip is a dumb component. It fires the `onDelete` callback, but you must update your parent component's state to actually remove the chip from the DOM.

**Q: Can I put a ReactNode instead of a string in the label prop?**
A: No, the `label` prop is typed strictly as a `string`. If you need custom JSX inside the pill, consider building a custom element using the `Box` primitive instead.

**Q: How do I change the default delete icon?**
A: The SVG is hardcoded for consistency, but you can hide it via CSS and inject your own using `::after`, or build a custom chip if heavy modification is required.
