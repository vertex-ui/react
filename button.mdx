## Before You Start

By default, the component renders an HTML `<button type="button">`. It does not submit forms unless you explicitly pass `type="submit"`.

If you pass `asLink={true}`, it will seamlessly switch its underlying DOM node to an `<a>` tag while retaining the exact same visual button styling.

The Quick Start example below will produce a solid primary-colored button.

### Button Loading State

Set the `loading` prop to `true` to instantly disable the button and display a loading spinner. If you provide `loadingText`, the button's children will be temporarily replaced.

<!--
EXAMPLE: Loading State
PURPOSE: Demonstrates asynchronous action feedback
OUTPUT: A button with a spinner and changing text
USE WHEN: Waiting for an API response after clicking
SOURCE: app/storybook/src/stories/Button.stories.tsx
-->
```tsx
import { useState } from 'react';
import { Button } from '@luxis-ui/core';

export default function LoadingExample() {
  const [isLoading, setIsLoading] = useState(false);

  const handleClick = () => {
    setIsLoading(true);
    // Simulate network request
    setTimeout(() => setIsLoading(false), 2000);
  };

  return (
    <Button
      onClick={handleClick}
      loading={isLoading}
      loadingText="Processing Payment..."
    >
      Confirm Order
    </Button>
  );
}
```

## Button Best Practices

Proper button usage is critical for user flow and accessibility.

<DoAndDont
  good={`// ✅ Use type="submit" for form actions
<form onSubmit={handleSubmit}>
  <Button type="submit" variant="primary">Log In</Button>
</form>`}
  bad={`// ❌ Assume the button will submit the form automatically
<form onSubmit={handleSubmit}>
  <Button variant="primary">Log In</Button> // defaults to type="button"
</form>`}
/>

<DoAndDont
  good={`// ✅ Provide an aria-label for icon-only buttons
<Button iconOnly aria-label="Refresh data">
  <RefreshIcon />
</Button>`}
  bad={`// ❌ Leave icon-only buttons without accessible names
<Button iconOnly>
  <RefreshIcon />
</Button>`}
/>

<DoAndDont
  good={`// ✅ Use asLink when navigating to a URL
<Button asLink href="/dashboard" variant="primary">
  Go to Dashboard
</Button>`}
  bad={`// ❌ Use a router push inside an onClick for simple navigation
<Button onClick={() => router.push('/dashboard')}>
  Go to Dashboard
</Button>`}
/>

<DoAndDont
  good={`// ✅ Restrict to one primary button per view/section
<div className="modal-footer">
  <Button variant="ghost">Cancel</Button>
  <Button variant="primary">Confirm Payment</Button>
</div>`}
  bad={`// ❌ Place multiple primary buttons next to each other
<div className="modal-footer">
  <Button variant="primary">Cancel</Button>
  <Button variant="primary">Confirm Payment</Button>
</div>`}
/>

## Button Accessibility Guide

The Button component maps to native HTML elements, meaning it gets standard focus ring and keyboard interactions for free.

### Keyboard Shortcuts

| Key | Action |
|-----|--------|
| <KeyboardKey>Tab</KeyboardKey> | Moves focus to the button. |
| <KeyboardKey>Enter</KeyboardKey> | Triggers the `onClick` event. |
| <KeyboardKey>Space</KeyboardKey> | Triggers the `onClick` event (if it is a `<button>`, not an `<a>`). |

### ARIA Attributes

| Attribute | Value | When |
|-----------|-------|------|
| `role` | `"button"` | Not explicitly set because native `<button>` has implicit role. |
| `aria-disabled` | `"true"` | When `disabled` or `loading` is true. |
| `aria-busy` | `"true"` | When `loading` is true. |

### Accessibility Checklist

- [ ] Provide an `aria-label` whenever you use `iconOnly={true}`.
- [ ] If using an icon alongside text, you do not need an `aria-label` as long as the text describes the action. You should set `aria-hidden="true"` on the icon itself.

## Troubleshooting Button

### Common Mistakes

| Symptom | Wrong ❌ | Right ✅ |
|---------|---------|---------|
| Next.js `<Link>` causes a full page reload | Wrapping `<Button>` in `<Link>` | Set the global `linkComponent` in your `ThemeProvider` and use `<Button asLink href="...">` |
| Clicking button submits a form unexpectedly | Forgetting to set `type` | `<Button type="button">` prevents form submission (Luxis UI defaults to button, but native HTML defaults to submit if inside a form, so be explicit) |
| Screen readers ignore icon | `iconOnly` without `aria-label` | Add `aria-label="Action description"` |
| React warning about invalid DOM nesting | `<Button><div>...</div></Button>` | Do not put block elements like `div` inside a `<button>`. Use `span` or semantic inline formatting. |

### Frequently Asked Questions

**Q: Can I change the color of a specific variant globally?**
A: Yes, use your CSS stylesheet to redefine the CSS variable for the theme's core colors. For example, changing `--lxs-color-primary-500` will change all primary buttons.

**Q: How do I disable the hover effect?**
A: You can override the CSS class `.lxs-button:hover` or pass inline styles to reset `background-color` or `transform`.

**Q: Is the Button responsive?**
A: By default, it sizes itself to its text content. If you want it to fill a container on small screens, use the `fullWidth` prop.

**Q: Can I use an SVG instead of an emoji for an icon?**
A: Yes, the `leftIcon` and `rightIcon` props accept any valid React node, including imported SVG components.

```tsx
import { Button } from '@luxis-ui/core';
```

## Minimal usage
```tsx
import { Button } from '@luxis-ui/core';

export default function Example() {
  return (
    <Button variant="primary" onClick={() => alert("Action!")}>
      Click Me
    </Button>
  );
}
```

## Key props
- `variant` ('primary' | 'secondary' | 'outline' | 'ghost' | 'danger' | 'success' | 'warning', default='primary')
- `size` ('sm' | 'md' | 'lg')
- `loading` (boolean): Shows spinner and disables.
- `asLink` (boolean): Renders as anchor tag using the `href` prop.
- `iconOnly` (boolean): Sets padding for square aspect ratio (requires aria-label).
- `leftIcon` / `rightIcon` (ReactNode): Adds visual indicators.

## When to use
Form submissions, primary calls to action, opening modals, or distinct navigation.

## When NOT to use
Standard inline paragraph links (use Link). Status tags (use Badge).

## Accessibility
WCAG: AA
ARIA: button
Keyboard: Tab, Enter, Space
