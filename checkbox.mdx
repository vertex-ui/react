## Before You Start

Unlike native HTML `<button>` tags where text is passed as `children`, the Luxis UI Checkbox expects its text description to be passed via the `label` prop. This ensures proper DOM structuring (wrapping the hidden input and the text in a single label) and prevents React layout errors.

The Quick Start example below will render a standard primary-colored checkbox.

## How to Use Checkbox in React

<!--
EXAMPLE: Basic Usage

import { useState } from 'react';
import { Checkbox } from '@luxis-ui/core';

export default function Example() {
  const [agreed, setAgreed] = useState(false);

    />
  );
}

### Checkbox Indeterminate State

The `indeterminate` state is a visual-only state (it does not strictly affect the underlying HTML `checked` boolean value conceptually) used primarily in "Select All" scenarios when a list is partially selected.

<!--
EXAMPLE: Indeterminate State
PURPOSE: Demonstrates partial selection
OUTPUT: A checkbox with a horizontal dash instead of a checkmark
USE WHEN: A parent checkbox controls a list where only some children are checked
SOURCE: app/storybook/src/stories/Checkbox.stories.tsx
-->
```tsx
import { useState } from 'react';
import { Checkbox } from '@luxis-ui/core';

export default function IndeterminateExample() {
  const [checkedItems, setCheckedItems] = useState([true, false]);

  const allChecked = checkedItems.every(Boolean);
  const isIndeterminate = checkedItems.some(Boolean) && !allChecked;

  return (
    <div style={{ display: 'flex', flexDirection: 'column', gap: '8px' }}>
      <Checkbox
        label="Select All Privileges"
        checked={allChecked}
        indeterminate={isIndeterminate}
        onChange={(e) => setCheckedItems([e.target.checked, e.target.checked])}
      />
      <div style={{ paddingLeft: '24px', display: 'flex', flexDirection: 'column', gap: '8px' }}>
        <Checkbox
          label="Read Access"
          checked={checkedItems[0]}
          onChange={(e) => setCheckedItems([e.target.checked, checkedItems[1]])}
        />
        <Checkbox
          label="Write Access"
          checked={checkedItems[1]}
          onChange={(e) => setCheckedItems([checkedItems[0], e.target.checked])}
        />
      </div>
    </div>
  );
}
```

## Checkbox Accessibility Guide

The Checkbox component relies on native HTML semantics, ensuring perfect accessibility without requiring complex ARIA attributes.

### Keyboard Shortcuts

| Key | Action |
|-----|--------|
| <KeyboardKey>Tab</KeyboardKey> | Moves focus to the checkbox. |
| <KeyboardKey>Space</KeyboardKey> | Toggles the checked state. |

### Screen Reader Behavior

The component renders a standard `<label>` that directly wraps the native `<input type="checkbox">`. Because of this implicit wrapping, screen readers will automatically read the `label` text when the input is focused, and will accurately announce the current `checked` or `disabled` state natively.

### Accessibility Checklist

- [ ] Ensure every checkbox has a `label` prop. If you are building a custom grid layout where the label is visually hidden elsewhere, pass `aria-label` directly to the component.
- [ ] If using `helperText` that contains vital instructions, ensure it is linked via `aria-describedby` manually if strict adherence is required, though visual proximity usually suffices.

### Using with forwardRef

The `ref` is forwarded directly to the hidden native `<input type="checkbox">` element, allowing you to focus it programmatically or hook it into uncontrolled form libraries like `react-hook-form`.

export default function RefExample() {

}

## Troubleshooting Checkbox

### Common Mistakes

| Symptom | Wrong ❌ | Right ✅ |
|---------|---------|---------|
| "Void element" error crashes React | `<Checkbox>Text</Checkbox>` | Use `<Checkbox label="Text" />` |
| Form state doesn't update | Using `value={checked}` | Checkboxes use `checked` and `onChange(e => e.target.checked)` |
| Label text is not clickable | Wrapping Checkbox in your own `<label>` | Luxis UI Checkbox already wraps itself in a `<label>`. Do not double-wrap. |
| Custom styles ignored | Setting `className` on the box | Use `boxClassName` for the visual square, and `className` for the wrapper. |

### Frequently Asked Questions

**Q: Can I change the checkmark color?**
A: Yes, use the `variant` prop to change the background and border color. The checkmark icon itself is always white/transparent to contrast with the semantic background.

**Q: Is it responsive?**
A: Yes, the container is `display: flex` and the text will wrap naturally if placed in a narrow container.

**Q: How do I manage an array of checkboxes easily?**
A: Do not manage multiple single `Checkbox` components manually. Use the `<CheckboxGroup>` component which manages the array state for you automatically.
