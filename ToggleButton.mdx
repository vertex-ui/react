  Luxis UI `ToggleButton` is equivalent to MUI's `<Switch>`,
  Chakra UI's `<Switch>`, and shadcn/ui's `Switch`.
  Unlike MUI, it includes built-in label and helper text layout without an external wrapper.

## Before You Start

ToggleButton represents a setting that takes immediate effect when changed.
It is based on the HTML `input type="checkbox"` with `role="switch"`.
The Quick Start example below will produce a basic uncontrolled switch with a label.

### ToggleButton BulkToggle

Implement a master toggle to control a group of related settings.

<!--
EXAMPLE: BulkToggle
PURPOSE: Shows a master toggle overriding children
OUTPUT: A large main switch and smaller sub-switches
USE WHEN: Providing an easy way to enable/disable an entire category of features
SOURCE: app/storybook/src/stories/ToggleButton.stories.ts → BulkToggle
-->
```tsx
import { useState } from 'react';
import { ToggleButton } from '@luxis-ui/core';

const FEATURES = ['Dark mode', 'Compact layout', 'Animations'];

export default function BulkToggleExample() {
  const [checks, setChecks] = useState([true, false, true]);

  const allOn = checks.every(Boolean);
  const someOn = checks.some(Boolean);

  const toggleAll = (on: boolean) => setChecks(checks.map(() => on));
  const toggleOne = (i: number, on: boolean) =>
    setChecks((prev) => prev.map((v, idx) => (idx === i ? on : v)));

  return (
    <div style={{ display: 'flex', flexDirection: 'column', gap: 12 }}>
      <ToggleButton
        label={allOn ? 'Disable all' : someOn ? 'Enable remaining' : 'Enable all'}
        checked={allOn}
        onChange={(e) => toggleAll(e.target.checked)}
        variant="secondary"
        size="lg"
      />
      <hr style={{ border: 'none', borderTop: '1px solid #e5e7eb' }} />
      {FEATURES.map((feature, i) => (
        <ToggleButton
          key={feature}
          label={feature}
          checked={checks[i]}
          onChange={(e) => toggleOne(i, e.target.checked)}
          size="sm"
        />
      ))}
    </div>
  );
}
```

This renders a group where the top toggle controls the state of all items below it.

## ToggleButton Best Practices

Use toggles correctly to avoid user confusion about form submissions.

<DoAndDont
  good={`// ✅ Use for settings that apply instantly
<ToggleButton label="Airplane Mode" onChange={updateNetworkSetting} />`}
  bad={`// ❌ Don't use inside forms requiring a "Save" button
<form>
  <ToggleButton label="Subscribe to newsletter" />
  <Button type="submit">Save</Button>
</form>`}
/>

<DoAndDont
  good={`// ✅ Write positive, declarative labels
<ToggleButton label="Enable Auto-Save" />`}
  bad={`// ❌ Don't use negative language that creates double-negatives
<ToggleButton label="Disable Auto-Save" />`}
/>

<DoAndDont
  good={`// ✅ Use checkboxes for lists of multiple items
<CheckboxGroup>
  <Checkbox label="Admin" />
  <Checkbox label="Editor" />
</CheckboxGroup>`}
  bad={`// ❌ Don't use a list of toggles for selecting roles
<div>
  <ToggleButton label="Admin" />
  <ToggleButton label="Editor" />
</div>`}
/>

<DoAndDont
  good={`// ✅ Change variant to indicate impact

## ToggleButton Props & API Reference

Complete reference for all props. All types and defaults sourced directly
from `packages/luxis-ui/src/components/ToggleButton/ToggleButton.tsx`.

### ToggleButton Props

| Prop | Type | Default | Required | Description |
|------|------|---------|----------|-------------|
| `checked` | `boolean` | - | No | If true, the toggle button is checked |
| `checkedIcon` | `ReactNode` | - | No | Icon to display inside the toggle knob when checked. Overrides `icon` when checked. |
| `className` | `string` | `''` | No | Additional CSS class name for the container |
| `disabled` | `boolean` | `false` | No | If true, the toggle button is disabled |
| `error` | `boolean` | `false` | No | If true, displays error styling |
| `helperText` | `ReactNode` | - | No | Helper text displayed below the toggle button |
| `icon` | `ReactNode` | - | No | Icon to display inside the toggle knob (thumb) |
| `inputClassName` | `string` | `''` | No | Additional CSS class name for the input element |

## ToggleButton Accessibility Guide

ToggleButton follows the WAI-ARIA Switch pattern and meets WCAG AA.

### Keyboard Shortcuts

| Key | Action |
|-----|--------|
| <KeyboardKey>Tab</KeyboardKey> | Focuses the toggle switch |
| <KeyboardKey>Space</KeyboardKey> | Toggles the checked state |

### ARIA Attributes

| Attribute | Value | When |
|-----------|-------|------|
| `role` | `"switch"` | Always on the input |
| `id` | `[string]` | Always generated and linked to the label via `htmlFor` |

### Screen Reader Behavior

When focused, screen readers will announce the input as a "switch", read the text of the connected `<label>`, and announce whether it is currently "on" or "off" (checked/unchecked). The semantic `role="switch"` conveys that this control takes immediate action.

### Accessibility Checklist

- [ ] Provide a descriptive \`label\` prop or visibly hide it via CSS if the layout implies the meaning
- [ ] Ensure any \`helperText\` clearly explains the consequences of toggling the switch
- [ ] Do not nest interactive elements inside the label
- [ ] Always test with keyboard-only navigation before shipping

## Troubleshooting ToggleButton

### Common Mistakes

| Symptom | Wrong ❌ | Right ✅ |
|---------|---------|---------|
| Label click doesn't toggle | Missing or invalid \`id\` when manually linking external label | Let ToggleButton handle the internal \`<label>\` rendering automatically |
| Toggle state resets unexpectedly | Missing \`onChange\` handler on a controlled component | Sync \`checked\` state with a React \`useState\` setter |
| Icon is distorted | Supplying a non-square SVG | Ensure the passed SVG has a \`0 0 24 24\` viewBox |
| Switch doesn't align with text | Wrapping in a flex container with wrong \`align-items\` | Use \`labelPlacement="start"\` or standard flex properties |

<Callout type="warning" title="Next.js / SSR">
  Ensure the \`id\` prop is stable during SSR hydration to avoid mismatch warnings between the \`label\` and \`input\`.
</Callout>

### Frequently Asked Questions

**Q: Can I change the color of the thumb instead of the track?**
A: Yes, you can override the thumb's background color via CSS targeting \`.lxs-toggle-button-thumb\`.

**Q: How do I submit the toggle value in a native HTML form?**
A: Ensure you pass a \`name\` prop. The input will submit its value ("on") if it is checked. However, remember Checkboxes are usually better for forms.

**Q: Why isn't my icon showing?**
A: The icon must fit inside the thumb area. Ensure your SVG uses \`width="100%"\` and \`height="100%"\` so it scales down to the thumb size.

**Q: Can I use ToggleButton instead of Checkbox everywhere?**
A: No. ToggleButtons should only be used when the action takes effect immediately (like a light switch). Checkboxes are for selecting options that require a final "Submit" button to save.
