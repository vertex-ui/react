<ComponentStatus status="stable" version="1.0.0" aria="Group" />

## Before You Start

A CheckboxGroup manages multiple `Checkbox` components based on an array of data. It outputs an array of selected string values.
The Quick Start example below will produce a vertical list of checkboxes with a shared label above them.

### Controlled CheckboxGroup

When to use: When a parent component needs to read or drive the state.

  By default CheckboxGroup manages its own state (uncontrolled).
  Use the controlled pattern when syncing with a URL param, form
  library, or another component.
</Callout>

```tsx
import { useState } from 'react';

export default function ControlledExample() {

    <div>

        value={value}
        onChange={setValue}

      <p style={{ marginTop: 12, color: '#666', fontSize: 13 }}>
```

## CheckboxGroup Best Practices

Groups help users process forms faster. Keep the logic clear and the layouts consistent.

<DoAndDont
  good={`// ✅ Use the options array for clean data mapping
<CheckboxGroup options={data.map(d => ({ value: d.id, label: d.name }))} />`}
  bad={`// ❌ Build manual groups and manually track array state
<div>
  <Checkbox onChange={(e) => updateState('1', e.target.checked)} />
  <Checkbox onChange={(e) => updateState('2', e.target.checked)} />
</div>`}
/>

<DoAndDont
  good={`// ✅ Use horizontal orientation for 2-3 short items
<CheckboxGroup orientation="horizontal" options={[{value: 'yes', label: 'Yes'}, {value: 'no', label: 'No'}]} />`}
  bad={`// ❌ Use horizontal orientation for 10 long items
<CheckboxGroup orientation="horizontal" options={longOptionsArray} />`}
/>

<DoAndDont
  good={`// ✅ Pass the error prop to the group so it styles the whole fieldset
<CheckboxGroup error={hasError} helperText={errorMessage} options={options} />`}
  bad={`// ❌ Try to map errors to individual checkboxes inside a group manually
<CheckboxGroup options={options.map(o => ({ ...o, error: hasError }))} />`}
/>

<DoAndDont
  good={`// ✅ Provide a clear label for the group
<CheckboxGroup label="Select your dietary requirements" options={options} />`}
  bad={`// ❌ Omit the label, leaving users to guess the context
<CheckboxGroup options={options} />`}
/>

## CheckboxGroup Accessibility Guide

CheckboxGroup visually groups inputs. While currently rendering a `div`, it applies proper spacing and structure. For strict adherence, ensure the containing form utilizes proper fieldsets if required by your application context.

### Keyboard Shortcuts

| Key | Action |
|-----|--------|
| <KeyboardKey>Tab</KeyboardKey> | Moves focus sequentially through each enabled checkbox in the group |
| <KeyboardKey>Space</KeyboardKey> | Toggles the checked state of the currently focused checkbox |

### ARIA Attributes

| Attribute | Value | When |
|-----------|-------|------|
| `aria-invalid` | `"true"` | (On inner checkboxes) When `error` is true |

### Screen Reader Behavior

Screen readers will announce the overall group label if wrapped correctly in your form. As the user tabs through the options, the screen reader announces each checkbox label individually along with its checked/unchecked status.

### Accessibility Checklist

- [ ] Ensure the `label` prop is clear and descriptive so users understand what the group is for.
- [ ] If using custom DOM structure around the group, consider adding `role="group"` and `aria-labelledby` pointing to your custom heading.
- [ ] Always provide `helperText` alongside the `error` state to explain *why* the group is invalid.
- [ ] Always test with keyboard-only navigation before shipping

## CheckboxGroup Design Tokens

<Callout type="tip" title="What are design tokens?">
  Design tokens are CSS custom properties that store design decisions
  like colors, spacing, and radius. CheckboxGroup relies on global spacing tokens and inherits Checkbox tokens.
</Callout>

| Token | Default Value | Description |
|-------|--------------|-------------|
| `--lxs-spacing-1` | `4px` | Spacing between label, options, and helper text |
| `--lxs-spacing-2` | `8px` | Gap between elements in vertical layout |
| `--lxs-spacing-3` | `12px` | Gap between elements in horizontal layout |

**Override globally:**
```css
:root {
  --lxs-spacing-2: 12px; /* Increases vertical gap for all groups */
}
```

**Override for one section:**
```css
.compact-form {
  --lxs-spacing-2: 4px;
}
```

**Override on one instance:**
```tsx
<CheckboxGroup
  style={{ gap: '16px' } as React.CSSProperties}
  options={options}
/>
```

```tsx
import { useState } from 'react';
import { CheckboxGroup, Checkbox } from '@luxis-ui/core';

export default function SelectAllIntegration() {
  const options = [
    { value: 'create', label: 'Create Records' },
    { value: 'read', label: 'Read Records' },
    { value: 'update', label: 'Update Records' },
    { value: 'delete', label: 'Delete Records' },
  ];

  const allValues = options.map((o) => o.value);
  const [value, setValue] = useState<string[]>(['read']);

  const allChecked = value.length === allValues.length;
  const isIndeterminate = value.length > 0 && !allChecked;

  const handleSelectAll = (checked: boolean) => {
    setValue(checked ? allValues : []);
  };

  return (
    <div style={{ display: 'flex', flexDirection: 'column', gap: '8px' }}>
      <Checkbox
        label={<strong style={{ fontSize: '14px' }}>Full Access</strong>}
        checked={allChecked}
        indeterminate={isIndeterminate}
        onChange={(e) => handleSelectAll(e.target.checked)}
      />
      <div style={{ paddingLeft: '24px', paddingTop: '8px', borderLeft: '2px solid #f0f0f0', marginLeft: '10px' }}>
        <CheckboxGroup
          label=""
          options={options}
          value={value}
          onChange={setValue}
        />
      </div>
    </div>
  );
}
```

### Form Validation Pattern

Used when: Validating that a user has selected required minimums in a form.

<!--
EXAMPLE: Form Validation Pattern
PURPOSE: Demonstrates external validation logic applied to the group
OUTPUT: A group that turns red if submitted without selections
USE WHEN: Building multi-step forms or surveys
SOURCE: Common usage pattern for CheckboxGroup
-->
```tsx
import { useState } from 'react';
import { CheckboxGroup } from '@luxis-ui/core';

export default function ValidatedForm() {
  const [value, setValue] = useState<string[]>([]);
  const [touched, setTouched] = useState(false);

  const options = [
    { value: 'news', label: 'Company News' },
    { value: 'product', label: 'Product Updates' },
    { value: 'events', label: 'Local Events' }
  ];

  const hasError = touched && value.length === 0;

  const handleSubmit = (e: React.FormEvent) => {
    e.preventDefault();
    setTouched(true);
    if (value.length > 0) {
      alert(`Submitted: ${value.join(', ')}`);
    }
  };

  return (
    <form onSubmit={handleSubmit} style={{ display: 'flex', flexDirection: 'column', gap: '16px', maxWidth: '300px' }}>
      <CheckboxGroup
        label="Mailing List Topics *"
        options={options}
        value={value}
        onChange={(val) => {
          setValue(val);
          if (touched) setTouched(true);
        }}
        error={hasError}
        helperText={hasError ? "You must select at least one topic." : "Select all that apply."}
      />
      <button
        type="submit"
        style={{ padding: '8px', background: 'var(--lxs-color-primary-600)', color: 'white', border: 'none', borderRadius: '4px', cursor: 'pointer' }}
      >
        Save Preferences
      </button>
    </form>
  );
}
```

## Troubleshooting CheckboxGroup

### Common Mistakes

| Symptom | Wrong ❌ | Right ✅ |
|---------|---------|---------|
| My onChange function receives an event object | Typing `onChange={(e) => ...}` | Typing `onChange={(valueArray) => ...}` |
| State doesn't update | Mutating the value array directly | Calling the setter function with a new array |
| The group label is squished | Trying to override internal padding | Use `margin` on the parent container |
| Child options won't disable | Passing disabled as a separate array | Put `disabled: true` inside the option object |

### Frequently Asked Questions

**Q: Can I use custom components as the label in the options array?**
A: Yes, the `label` property in the `options` array accepts `React.ReactNode`, so you can pass JSX, icons, or formatted text.

**Q: How do I change the color of the checkboxes inside the group?**
A: CheckboxGroup uses the default `primary` variant of the underlying `Checkbox` component. To change it globally or locally, override the CSS variable `--lxs-checkbox-color` on the group container.

**Q: Is there a way to limit the maximum number of selections?**
A: You must handle this in your `onChange` handler by checking the array length before updating your state, and optionally passing `disabled: true` to unselected options dynamically.

**Q: Why doesn't the group use standard HTML `<fieldset>` and `<legend>`?**
A: The `div` structure provides more consistent cross-browser styling. For strict semantic requirements, you can wrap the `CheckboxGroup` in a native `fieldset` yourself.
